# Frend

Proyecto React con Vite y Storybook.

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Storybook

Para lanzar Storybook en local:

```bash
npm run storybook
```

Se abrirá en [http://localhost:6006](http://localhost:6006).

## Build

```bash
npm run build
```
